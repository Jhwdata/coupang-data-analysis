##  3. 핵심 분석 및 인사이트 (Key Insights)

### 1. 높은 쿠팡 멤버십 의존도
* 전체 구매의 대다수가 로켓배송을 통해 이루어짐. 빠른 배송 서비스가 소비자의 구매 결정에 미치는 압도적인 영향력 확인.
* 반품률이 다소 높게 나타난 카테고리(예: 패션의류/잡화 등)를 살펴보면, '직접 입어보기 전에는 알기 어려운 상품 특성'이 반영되어 있음. 쿠팡의 **'무료 반품'** 혜택 덕분에 반품에 대한 부담이 줄어들어, 오히려 의류처럼 실패 확률이 있는 상품도 더 과감하고 편리하게 주문하게 되는 소비 패턴을 보여줌.

### 2. 카테고리별 '반품률' 리스크 분석
* `[카테고리별 반품 건수] / [카테고리별 전체 주문 건수]` 공식을 통해 정규화 진행.
* 태블로를 활용하여 긴 카테고리명의 가독성을 높이고 진짜 반품 리스크가 높은 카테고리를 시각적으로 명확하게 도출.

### 3. 꾸준한 우상향을 그린 월별 지출 트렌드
* 1월부터 7월까지 총 **1,160,600원**(70건)을 지출했으며 평균 주문 금액은 **약 16,580원**으로 주로 부담 없는 소액 생필품 위주의 구매가 주를 이룸.

### 4. 합리적인 할인 혜택 활용과 반품 구조
* 7개월간 총 **85,160원**의 할인 혜택을 알뜰하게 챙김.
* 전체 주문 중 반품 비율은 **28.97%**로 나타났으나, 멤버십 혜택 등을 통해 불필요한 비용 손실 없이 유연하게 소비를 관리하고 있음.

### 5. 반복 구매 품목으로 드러난 고정소비
* **주요 소비 카테고리:** '식품'과 '생활용품'이 지출의 가장 큰 비중을 차지함.수량 대비 결제 금액이 높지 않음 
* **자주 구매한 상품 TOP:** 식품, 생활용품, 간편식 및 음료가 상위권을 차지해, 일상적인 식음료와 소모품 주기 갱신이 주된 소비 패턴임을 보여줌.

### 6. 과한 지출 없는 안전한 소비
* **데이터 착시 현상 발생:** 초기 총 결제금액 기준으로 지출 데이터를 살펴봤을 때, 특정 구간에서 수치가 유독 높게 튀는 고액 지출 구간이 포착됨.
* **원인 분석:** 해당 내역을 추적한 결과, 여러 상품이 한 번에 묶여서 배송되는 **합포장(묶음 배송)** 특성 때문에 단일 결제 금액이 비정상적으로 부풀려져 나타난 것임을 확인.
* **주문 번호별 단가 검증:** 이에 그치지 않고, 주문 번호에 따른 개별 상품 가격을 기준으로 재검증(조건 필터링)을 진행함. 그 결과 해당 고액 건들은 단 5건으로 줄어들었으며, **단가가 원래 높은 내구재/고단가 생필품**을 구매한 것뿐임을 확인.
* **결론:** 일시적인 합포장으로 인해 발생한 착시일 뿐, 불필요한 낭비나 '과한 지출'이 아닌 계획적이고 정상적인 소비 패턴임을 확인
