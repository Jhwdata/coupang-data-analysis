# 🛍️ 2026 쿠팡 구매 데이터 기반 BI 대시보드 프로젝트

> 실제 본인의 7개월간 소비 패턴 데이터(내돈내산)를 크롤링을 통해 데이터를 추출한 뒤 Python으로 정제하고, 기획을 거쳐 데이터 분석 프로젝트입니다.

## 1. 프로젝트 개요 (Overview)
* **프로젝트 기간:** 2026년 (약 1~7월 데이터 활용)
* **주요 목적:** 내돈내산 소비 데이터 정제, 쿠팡 이용 패턴 분석 및 시각화
* **사용 툴 (Tech Stack):** Python(Colab), Tebleau, Figma
* **Key Metrics (핵심 지표):**
  * 총 지출액: **약 116만 원** (총 70건)
  * 평균주문금액: **16,580**
  * 로켓배송 의존도: **96.55%**
  * 전체 반품률: **28.97%**

## 2. 데이터 수집 및 전처리 (Data Pipeline & Preprocessing)

### 🔹 데이터 수집
* Python `Selenium`을 활용하여 쿠팡 주문/배송 내역 크롤링 및 파싱 자동화 (`coupang.py`)

### 🔹 이상치(Outlier) 검증 및 보정
* **문제 상황:** 초기 총 결제금액 기준 고액 지출 구간 필터링 시 금액이 비정상적으로 부풀려진 현상 포착
* **원인 분석:** 일시적인 묶음 배송(합포장) 데이터 특성으로 인해 발생한 착시 현상
* **해결 방안:** 단일 상품 '가격' 기준(`가격 >= 23,878 & 반품여부 == 0`)으로 조건을 재정의하여 엔진오일, 단백질 보충제, 매트리스 커버 등 **내구재/고단가 생필품에 의한 정상 소비 패턴**임을 검증 및 보정 완료

## 💡 3. 핵심 분석 및 인사이트 (Key Insights)

### ① 극단적인 로켓배송 의존도 (96.55%)
* 전체 구매의 대다수가 로켓배송을 통해 이루어짐. 빠른 배송 서비스가 소비자의 구매 결정에 미치는 압도적인 영향력 확인.

### ② 높은 반품률과 멤버십 효용성 방어
* 표면상 반품률이 **28.97%**로 다소 높게 나타남.
* 그러나 카테고리별 정규화 분석 및 배송 비용 구조를 살펴본 결과, **로켓와우 멤버십의 무료 반품 혜택**을 적극 활용하여 불필요한 추가 비용 발생을 철저하게 방어하고 있음을 증명.

### ③ 카테고리별 '진짜 반품률' 리스크 분석
* 단순 '절대 반품 건수'만 볼 경우, 구매량이 많은 주력 카테고리에서 반품이 많아 보이는 착시 현상 발생.
* `[카테고리별 반품 건수] / [카테고리별 전체 주문 건수]` 공식을 통해 정규화 진행.
* 태블로 **가로 막대 그래프(Horizontal Bar Chart)**를 활용하여 긴 카테고리명의 가독성을 높이고 진짜 반품 리스크가 높은 카테고리를 시각적으로 명확하게 도출.
